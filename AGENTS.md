# Öffentliche FLEET-Webservice-Dokumentation

Dieses Repo wird aus dem Webservice-Quellprojekt synchronisiert. Änderungen an
Vorlagen, Funktionsreferenz oder Skripten auch dort übernehmen, damit sie bei der
nächsten Veröffentlichung erhalten bleiben. Vor jedem Commit/Push ChangeLog,
Installations- und Updateskripte sowie Downloads aktualisieren und
`python -m mkdocs build --strict` prüfen. Keine Zugangsdaten oder internen
Kunden-/Serverinformationen veröffentlichen. Deployment erfolgt bei Push auf main.
